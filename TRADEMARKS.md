# The recursiva name and mark

The code is open source (see `LICENSE`); the name **recursiva** and the recursiva mark are not part of that license.

You may:

- say that your product works with recursiva, or that you run recursiva yourself, using the name in plain text;
- link to rsva.dev and use the name to describe recursiva itself, accurately;
- keep the name and mark in an unmodified copy of the code you run for yourself or your team.

Ask us first (rsva.dev) if you want to:

- offer a hosted service called recursiva, or a name close enough to be confused with it;
- use the mark, or a changed version of it, for your product, service, company or domain;
- ship a modified build to other people under the recursiva name.

A fork is welcome under the code's license; give it a name of its own.
